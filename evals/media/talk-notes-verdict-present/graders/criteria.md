# Pass criteria — talk-notes-verdict-present

Per `skills/talk-notes/SKILL.md` Method step 4, output must extract into a fixed shape including a **Verdict**.

1. Output contains an explicit, labeled Verdict (or clearly equivalent heading) — not folded silently into a closing paragraph.
2. The verdict states one of: watch fully / notes suffice / skip (or an unambiguous equivalent), not a vague "this was interesting."
3. The verdict includes a one-sentence reason tied to relevance — specifically to a stated stack/context, not a content-quality judgment alone (e.g. "low relevance, this repo has no Java footprint" passes; "well-produced video" alone fails — the second is a quality opinion, not a relevance verdict).

Fails if any of the fixed-shape sections (Metadata, Thesis, Sections, Key claims, Actionable takeaways, Verdict) are missing entirely, not just the Verdict — but the Verdict's presence and shape is the primary thing graded here.
